File reference

main.py
Entry point. Starts the asyncio event loop, instantiates AlbotBrain, and awaits all tasks.
AlbotBrain.py
Central hub. Constructs every component, wires their references together, launches the five async tasks, and handles graceful shutdown.
TwitchConnection.py
Manages the IRC websocket connection to Twitch. Handles login, chat send/receive, OAuth token loading and expiry checks.
Message_central.py
Parses raw IRC messages into sender + command, safety-checks input for injection characters, and forwards valid commands to Command_central.
UserRoleManager.py
Builds and caches lists of MODs, VIPs, subscribers, and followers via the Twitch API. Used for privilege checking.
command_handler.py
Reads command definitions from CSV files, validates commands, checks user privileges, and routes them to the appropriate queue.
command_runner.py
Consumes the command queues and executes text/chat-based commands (replies, shout-outs, etc.).
overlay_runner.py
Maintains the visual command queue. Builds the gif/text/sound payload for each event and sends it to the overlay bridge.
overlay_bridge.py
Qt signal bridge. Translates bot-side method calls into PySide6 signals that the UI thread can safely receive.
overlay.py
The PySide6 overlay window. Frameless, always-on-top, transparent background. Renders gif animations and greeting text on stream.
overlay_animations.py
AnimatedLabel and AnimationManager helpers — bounce, fade, and other effects used by the overlay window.
GifHandler.py
Loads known_gifs.csv, maps usernames to their gif, organises themed gif lists, and provides path/duration lookups.
TenorConnection.py
Downloads gif files from the Tenor API by ID and saves them locally. Skips download if file already exists.
databasecontroller.py
SQLite wrapper. Manages the errors register and tokens register tables. Named per hostname so each machine gets its own DB.
logger.py
Custom logging setup. Writes INFO to file, errors/warnings also to the SQLite errors register. Passed to every component at init.
